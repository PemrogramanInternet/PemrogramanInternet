Skill, Minat & Kemampuan

Beberapa kemampuan dan bidang yang sedang saya pelajari serta kembangkan dalam dunia teknologi.

Programming

Saya memiliki ketertarikan dalam pemrograman dan pengembangan perangkat lunak.

  • HTML

    Memahami struktur dan semantic HTML untuk membangun struktur dasar sebuah website.

    Level: Intermediate

  • CSS

    Memahami dasar styling, layout, responsive design, serta pembuatan tampilan website.

    Level: Intermediate

  • JavaScript

    Mempelajari JavaScript untuk menambahkan interaksi dan fungsi pada website.

    Level: Basic

  • Programming Logic

    Memahami dasar algoritma, logika pemrograman, serta problem solving dalam proses pengembangan aplikasi.

Web Development

Memiliki minat dalam membangun website yang terstruktur, responsif, dan mudah digunakan.

  • Front-End Development

    Membuat struktur dan tampilan website menggunakan HTML, CSS, dan JavaScript.

  • Responsive Web Design

    Mempelajari cara membuat tampilan website yang dapat menyesuaikan berbagai ukuran layar.

  • Database

    Memahami dasar pengelolaan database serta hubungan data dalam sebuah aplikasi.

UI/UX Design

Saya tertarik pada proses merancang antarmuka yang menarik sekaligus memberikan pengalaman pengguna yang baik.

  • User Interface Design

    Mempelajari bagaimana membuat desain antarmuka yang sederhana, menarik, dan mudah digunakan.

  • User Experience

    Memahami dasar user experience dan bagaimana merancang sebuah produk berdasarkan kebutuhan pengguna.

  • Design & Prototyping

    Membuat wireframe, prototype, serta mengeksplorasi berbagai konsep desain sebelum masuk ke tahap pengembangan.

Tools & Technology

Beberapa tools yang saya gunakan untuk membantu proses belajar, development, dan design.

  • Visual Studio Code

    Code editor yang digunakan untuk proses pengembangan website dan aplikasi.

  • Git & GitHub

    Digunakan untuk version control dan menyimpan serta mengelola source code.

  • Figma

    Digunakan untuk membuat desain UI, wireframe, dan prototype.
